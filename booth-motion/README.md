# 부스 터치 화면 모션

부스 키오스크 화면 1 → 8 전체 흐름입니다. Figma 화면(190×320 좌표)의 위치·크기·에셋을 그대로 옮기고 화면 전환 모션을 붙였습니다.

4번과 8번 화면은 같은 레포의 다른 폴더 페이지를 그대로 불러옵니다 (iframe). 코드를 복사해 두지 않으므로, 그 폴더를 고치면 booth에도 바로 반영됩니다.

| 화면 | 불러오는 페이지 | 주고받는 메시지 |
|---|---|---|
| 4 제품 소개 (폰 목업 속 결제 영상) | `../video-mockup/?embed` | 보냄: `video-mockup:play` (lang 포함) · `video-mockup:stop` / 받음: `video-mockup:end` |
| 8 결과 결제창 | `../ai-reveal-motion/demo/?embed` | 보냄: `ai-demo:reset` · `ai-demo:lang` |

그래서 booth 폴더만 따로 떼면 4번·8번이 비어 보입니다. 레포 폴더 구조(`booth-motion/`, `video-mockup/`, `ai-reveal-motion/`가 나란히)를 그대로 유지해서 띄워야 합니다.

## 파일

- `index.html`: 페이지 하나에 CSS·JS가 모두 들어 있음 (빌드 없음)
- `assets/`: 화면 이미지, 결제수단 로고, Wanted Sans 폰트. `card*_en.png`는 영어 모드용

## 화면 흐름

| 화면 | 내용 | 다음으로 넘어가는 조건 |
|---|---|---|
| 1 인트로 | 결제 장면 슬라이드 반복 | 화면 터치 |
| 2 문제 제기 | 고객 말풍선 4개가 1초 간격으로 차례로 올라옴 | 화면 터치 |
| 3·4 솔루션 → 제품 | 폰 목업 속 결제 영상 재생 (video-mockup, 2배속) | 자동 (영상 끝나면) |
| 5 결제 수단 | 숫자 롤링 "140+" + 로고 | 화면 터치 |
| 6 언어 | 5개 언어 롤링 | 화면 터치 ([결제하기] 버튼 포함 어디든) |
| 7 체험 시작 | PayPal 버튼을 맨 위로 옮김 | 자동 (공유 요소 전환) |
| 8 결과 결제창 | PayPal이 결제창 자리에 안착 → AI 추천 결제창 체험 | 없음 (GNB [처음으로]로 1번부터) |

- **터치 규칙:** 애니메이션이 진행 중이어도 화면을 터치하면 끝나길 기다리지 않고 바로 다음 화면으로 넘어갑니다 (8번 제외). 화면이 넘어가는 도중에 터치하면 넘어가던 화면의 다음 화면으로 갑니다. 버튼을 누르면 그 버튼 동작만 실행됩니다.
- **하단 GNB (모든 화면, Figma 컴포넌트 `gnb`):** 화면 맨 아래 190 × 26 바에 버튼 3개
  - 이전 (U턴 화살표): 바로 앞 화면으로
  - 처음으로 (반시계 화살표): 1번부터 다시
  - 언어 (KR = '가' / EN = 'A'): KR ↔ EN. 보던 화면을 바뀐 언어로 다시 재생하고, 4번 영상과 8번 결제창도 같은 언어로 바뀜
- **상단 당김 패널:** 어느 화면이든 위쪽 가장자리에서 아래로 끌어내리면 열립니다. 뒤 화면은 그대로 진행됩니다. 처음으로 · 언어 · 이전은 GNB와 같고, 체험 끄기는 패널에만 있습니다 (화면이 검게 꺼지고, 검은 화면을 터치하면 1번부터 다시 시작).
- 8번 결제창은 GNB 위(높이 294)까지만 보입니다.
- 페이지에는 키오스크 화면만 있습니다. 검은 배경 가운데에 창 높이(또는 폭)에 맞춰 190:320 비율로 꽉 차게 그려집니다.

## 모션 기준

- 등장 `cubic-bezier(0.22, 1, 0.36, 1)`, 이동 `cubic-bezier(0.65, 0, 0.35, 1)`
- 전체 타이밍은 원래 값의 0.8배 (`BASE`)

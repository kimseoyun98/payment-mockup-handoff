# 부스 터치 화면 모션 (결제창 체험 전 단계)

부스 키오스크에서 결제창 체험(`ai-reveal-motion`)으로 들어가기 전까지의 인트로 화면 1 → 8 흐름입니다. Figma 화면(190×320 좌표)의 위치·크기·에셋을 그대로 옮기고 화면 전환 모션을 붙였습니다.

## 파일

- `index.html`: 페이지 하나에 CSS·JS가 모두 들어 있음 (빌드 없음)
- `assets/`: 화면 이미지, 결제수단 로고, Wanted Sans 폰트. `sb*-en.png`, `card*_en.png`는 영어 모드용

## 화면 흐름

| 화면 | 내용 | 다음으로 넘어가는 조건 |
|---|---|---|
| 1 인트로 | 결제 장면 슬라이드 반복 | 화면 터치 |
| 2 문제 제기 | 말풍선 카드가 차례로 올라옴 | 화면 터치 |
| 3·4 솔루션 → 제품 | 폰 목업 속 결제 프로토타입 재생 | 자동 (영상 끝나면) |
| 5 결제 수단 | 숫자 롤링 "140+" + 로고 | 화면 터치 |
| 6 언어 | 5개 언어 롤링 | 화면 터치 |
| 7 체험 시작 | PayPal 버튼을 맨 위로 옮김 | 자동 (공유 요소 전환) |
| 8 결과 결제창 | PayPal이 결제창 자리에 안착 | [체험 완료] 버튼 → 1번으로 |

- 어느 화면이든 위쪽 가장자리에서 아래로 끌어내리면 패널(처음으로 · 언어 KR/EN · 이전 · 체험 끄기)이 열립니다. 뒤 화면은 그대로 진행됩니다.
- 페이지에는 키오스크 화면만 있습니다. 검은 배경 가운데에 창 높이(또는 폭)에 맞춰 190:320 비율로 꽉 차게 그려집니다.
- 체험 끄기 후 검은 화면을 터치하면 1번부터 다시 시작합니다.

## 모션 기준

- 등장 `cubic-bezier(0.22, 1, 0.36, 1)`, 이동 `cubic-bezier(0.65, 0, 0.35, 1)`
- 전체 타이밍은 원래 값의 0.8배 (`BASE`)

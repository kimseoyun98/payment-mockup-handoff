# AI 작업 지시서: AI 추천 결제창 모션 붙이기

이 문서는 코딩 AI에게 그대로 넘기는 작업 지시서입니다. 사람이 읽을 설명은 `README.md`에 있습니다.

## 목표

기존 결제창 화면(Electron 앱, 웹 기술 기반)에 `src/`의 모션 모듈을 붙여서, 데모(`demo/`)와 같은 동작을 실제 결제창에서 재현한다.

## 지켜야 할 것

1. **`src/` 파일은 수정하지 말고 그대로 복사해서 쓴다.** 동작을 바꿔야 하면 옵션·훅·CSS 변수로 해결하고, 안 되면 사람에게 묻는다.
2. **`demo/`는 가짜 결제창이다.** 결제창 마크업·데이터·좌표를 가져오지 말고, `demo/demo.js` 맨 아래 '모듈 연결' 블록만 연결 예시로 참고한다.
3. **색은 토큰으로:** 결제창 요소 색을 `var(--md-sys-color-<역할>, <지금 쓰는 색>)`로 바꾼다. 두 번째 값은 반드시 지금 코드에 있는 색을 그대로 둔다 (테마 미선택 시 화면이 지금과 같아야 함). 역할은 README '결제창 요소 ↔ 토큰' 표를 따른다. 표에 없는 요소는 바꾸지 말고 목록으로 보고한다.
4. **`m3-theme.css/js/json`은 자동 생성 파일이다.** 직접 고치지 않는다.
5. 프레임워크(React 등)가 있으면 그 방식으로 감싸되, 모듈은 화면에 DOM이 붙은 뒤 한 번만 만든다 (예: `useEffect(() => {...}, [])`). 화면이 사라질 때 다시 만들지 않도록 주의한다.

## 작업 순서

1. `src/` 폴더를 프로젝트에 복사하고, `src/index.css`를 불러오고, `src/index.js`에서 가져온다.
2. 결제창 루트 요소를 찾는다 (헤더 ~ 결제수단 목록을 모두 포함하는 요소, `position: relative`).
3. **컬러 드롭다운:** 헤더의 팔레트 버튼 자리에 `createColorDropdown(헤더요소, { onSelect: (t) => setM3Theme(루트, t) })`. 기존 팔레트 버튼이 있으면 그 자리를 대체한다. 위치는 `.cp`에 CSS로 지정.
4. **색 토큰:** 체크리스트 3번 규칙대로 결제창 CSS를 바꾼다.
5. **Reveal:** AI가 바꾸는 영역(대표 결제수단 ~ 나라별 결제수단 목록)을 README '결제창 쪽에서 할 일' 2번 구조로 감싸고 `new GenerationReveal(rvRoot)`.
6. **스켈레톤:** README '스켈레톤 규칙'대로 `.rv-skel` 안에 도형을 만든다. 구조(배경·카드·타일)는 고정으로 깔고, 바뀌기 전 글자·로고는 `onBeforeReveal`에서 그 순간의 화면 기준으로 채운다.
7. **AI 버튼 + 채팅 모달 + 연결:** README '붙이는 방법' 3번 코드. 훅 내용:
   - `onBeforeReveal`: 스켈레톤 채우기 → 결제수단 영역을 추천 결과로 다시 렌더 (렌더 완료까지 await) → `.rv-sharp`, `.rv-blur`에 `setM3Theme(el, 'Rose')`
   - `onSweepStart`: 헤더 요소들에 `setM3Theme(el, 'Rose')` + 로고 교체
   - `onAfterReveal`: `setM3Theme(루트, 'Rose')` 후 위에서 붙인 부분별 테마를 `setM3Theme(el, null)`로 정리
8. 위치 CSS: `.ai-btn`, `.aic`를 데모처럼 결제창 오른쪽 아래에 배치 (`demo/demo.css`의 `.phone .ai-btn`, `.phone .aic` 참고).

## 확인할 것 (데모와 비교)

- [AI 추천] → 모달 열림 → 모달 안 터치로 타이핑 완성 → 보내기 → 생각 중 → 결과 → 모달 닫힘 → 스켈레톤 → 글로우가 쓸고 내려가며 새 결제수단 + Rose 색 → 버튼 사라짐
- 모달이 열려 있는 동안 팔레트 등 다른 버튼이 눌리지 않고, 바깥 터치·X로 모달만 닫힘 (결제창은 그대로, 버튼 원래대로)
- 테마를 안 골랐을 때 결제창 색이 작업 전과 완전히 같음
- 컬러칩 7개 각각 결제창 색이 바뀜
- 콘솔 에러 없음
